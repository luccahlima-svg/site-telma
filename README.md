# Site Telma Hoyler

Versão estática inspirada no site `telmahoyler.lovable.app`.

## Arquivos

- `index.html`: estrutura das páginas.
- `styles.css`: visual e responsividade.
- `script.js`: navegação por hash, carrossel e listas.
- `assets/imagens/`: imagens baixadas do site de referência.

## Como abrir

Abra `index.html` no navegador.
